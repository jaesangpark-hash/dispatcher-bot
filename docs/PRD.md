# PRD — 원본 자동 이관 에이전트

작성: 박재상 · 2026-09-03 · v1

| 항목 | 내용 |
|---|---|
| 한 줄 요약 | 원본 재수급 또는 수동 요청 시 Kuaikan 파일을 PIVO에 자동 업로드 |
| 문제 (Pain Point) | ① 규칙화 가능한 패턴(원본 파일 줘, 에디터 링크 줘, 납품일 확인해 등)을 매번 내가 직접 명령해야 정보를 받을 수 있음 ② 내부 공유 메시지 초안 요청 시 봇 출력이 업무 톤앤매너와 맞지 않음 |
| 목표 | 규칙화할 수 있는 패턴의 명령을 내가 직접 입력하는 일이 없어진다 |
| 사용자 | 박재상 (메인) |
| 핵심 기능 | ① 원본 재수급 완료 시 자동 트리거 → Kuaikan 다운로드 → PIVO 업로드 → 성공·실패 알림 ② 슬랙 명령으로 특정 작품·회차 수동 이관 요청 가능 (콰이칸 한정) |
| 입력 → 출력 | 재수급 완료 알림 또는 슬랙 명령 → Kuaikan PSD 다운로드 → PIVO 업로드 → 전처리 대기 → 슬랙에 완료/실패 메시지 |
| 데이터 · 도구 | 슬랙 (명령 수신 · 알림 발송) / 구글 시트 (작품·PIVO ID 조회) / Kuaikan 드라이브 (원본 파일 다운로드) / PIVO (업로드 대상) |
| 안 할 것 (이번 범위) | ① 메인: Kuaikan 이외 출판사로의 확장 ② 서브(능동 에이전트): PRD 명시 2가지 예시(원본 파일 링크 자동 제공, Totus 에디터 링크 자동 제공) 이외 기능 시도 |
| 완성 기준 | 규칙화 가능한 패턴 명령(원본 파일 줘, 에디터 링크 줘, 납품일 확인해 등)을 내가 직접 입력하는 일이 없어진다 |
| 2주차 완성 기준 | 원본 이관 명령 기능 한정으로 APM·CFM에게 권한 개방 — 해당 인원이 툰식이에게 이관 명령을 보내 결과를 직접 받을 수 있는 상태 |

## 핵심 기능 현황

**이미 있는 것**
- 한/중/일 타이틀·출판사명·경로 시트 (원본 재수급용)
- 원본 이관 API
- 원본 이관 툰식이 스크립트 (기본 흐름)

**아직 없는 것 (이번 3주 작업)**
- 시트 외 작품의 자연어 명령 해석 로직 완성 (현재 불안정)
- 대량·대용량 업로드 방식 결정 (직렬/병렬, 과부하 예방)
- 특이사항 대응 로직 (폴백, 파일 누락·깨짐 감지·보고)
- 서버 불안정으로 인한 중도 실패 및 파일 중복 이관 대응

## 서브 프로젝트 (병행 고도화)
- **능동 선제 대응 에이전트**: 작품·회차 문의 수신 시 원본·에디터 링크·과거 로그를 자동 제공 — 병행 고도화 중, 3주 완성 기준 별도 없음

## 아웃풋 톤앤매너
- 내부 공유 메시지 초안 요청 시 업무 스타일에 맞게 출력
- 기준 예시: 추후 업데이트

## 필요한 권한·API (운영진 확인 요청)
- Totus 에디터 링크 조회 방식 확인 필요 (API 있는지, 있다면 엔드포인트·인증 방식)
- 구글 시트 읽기 접근 방식 확인 필요 (서비스 계정 or OAuth)
- 과거 문의 로그 저장 위치·형식 결정 필요 (슬랙 히스토리 조회 vs 봇 내부 저장)

## 실행 위치·계정 (1주차)

| 항목 | 내용 |
|---|---|
| 슬랙봇 | 개인 제작, 팀 서버에서 운영 |
| Kuaikan | 쿠키 기반 스크립트 접근 (쿠키 자동 갱신 로직 있음·미검증 / 만료 주기 미파악) |
| PIVO | API 접근 |
| 구글 시트 | 툰식이 서비스 계정(SA)으로 접근 |
| 시크릿 보관 | `.env` 파일 (EC2 내 위치 미확인) |
| 실행 위치 | EC2 팀 서버 |
| 배포 방식 | main push → 즉시 배포. 본인 단독 배포, AI 검증 후 진행. 별도 확인자 없음 |
