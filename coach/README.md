# coach/ — 코치가 넣는 자료

이 폴더는 **2조 코치(송형민)** 가 넣는 세션 자료입니다. 참가자 산출물(`docs/`·코드)과는 별개이고, 코치만 여기에 씁니다.

- 커밋 메시지가 `coach:` 로 시작하면 코치가 넣은 것입니다. `/ax-report` 주간 보고의 "한 일"에는 넣지 마세요.
- 코치는 이 폴더를 **`ax-lab` 브랜치에만** 넣습니다. `main` 에는 넣지 않습니다(main push 가 자동 배포·봇 재시작이라서). 같은 자료의 보관 사본이 `Voithru-AX/lab1-jaesang-park` 의 `coach/` 에도 있습니다.
- 이 폴더의 파일을 고치고 싶으면 코치에게 말해 주세요. 직접 고쳐도 되지만 다음 세션 자료로 덮일 수 있습니다.

| 파일 | 내용 |
|---|---|
| `1주차/실행문서.md` | 1주차 세션에서 순서대로 진행할 것 · 붙여넣을 프롬프트 · 확인할 것 |
| `1주차/세션안내.md` | 세션 화면에 띄우는 공통 안내 (3주 여정 · 관문 · 진행 방법) |
