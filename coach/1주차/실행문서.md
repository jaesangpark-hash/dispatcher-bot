## 2. 실측 기록

실측 = **시작·끝 시각을 보고 잰 것**입니다. 기술지원 신청서의 "100분"은 기억으로 떠올린 값이라 추정입니다.

먼저 업무 정의부터. 1건 = 원본 재수급 1건을 **사람 손으로** 이관하는 것(PM 안내 → PIVO 업로드 → Totus 전송).

```
/ax-baseline
```

**(가) 시각을 보며 잰 기록이 있으면** — 잰 날짜로 입력합니다.

```
/ax-baseline YYYY-MM-DD N건 M분
```

날짜를 잰 날로, `N`·`M` 을 내 숫자로 바꿉니다. 메모를 물으면 "시작 10:05 끝 10:40" 처럼 근거를 적습니다.

**(나) 잰 기록이 없으면** — 툰식이가 이미 자동화한 플랫폼 말고, 아직 수작업인 플랫폼의 다음 재수급 1건에서 시작·끝 시각을 메모합니다. 그 전까지 실측 관문은 미통과이고, 그것이 정상입니다.

```
docs/BASELINE.md 를 읽고, 1건의 정의와 빈도가 지금 내 업무와 맞는지 나에게 확인해 줘.
다음 측정 예정일을 나에게 물어서, 내가 "적어" 라고 하면 "참고" 절에 "다음 측정: YYYY-MM-DD, 방법: ___" 한 줄로 적어 줘.
기록 표에는 아무것도 추가하지 마.
```
