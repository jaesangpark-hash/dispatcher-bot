> 장소는 채널 스레드 공지를 봐 주세요. 1:1 은 막혀서 요청하시면 잡습니다.

## 오늘 도착할 지점

**세 가지가 사실로 확인된 상태에서, 내 도구의 첫 연결을 시작한다.**
세 가지 = ① 이미 있나 ② 지금 얼마나 걸리나(실측) ③ 뭘 만들지 한 장. 이게 1주차 관문입니다.
오늘 관문을 다 못 넘어도 됩니다. 어디까지 됐고 무엇이 남았는지가 정확히 남으면 성공입니다.

## 오늘 순서 (11:00~12:00)

1. 3주 여정과 1주차 관문, 오늘 진행 방식
2. **각자 실행 문서 순서대로 Claude Code 진행** — 관문 단계(실측 기록 → PRD 자가 점검 → 계정·보관·갱신·위치). 코치는 돌아다닙니다
3. 전원 저장(`/ax-save`). 코치가 파일 기준으로 관문 판정
4. 공유: 완료한 것 · 막힌 것 · 다음 행동 한 줄씩 (계정·위치는 확인한 범위만)

오늘은 시간상 **관문 단계까지**입니다. 실행 문서의 구현 단계는 오늘 하지 않습니다. 관문을 넘은 분의 구현은 이번 주 각자 진행하고, 막히면 1:1 을 요청하시면 됩니다.

오늘은 코치가 한 사람씩 질문하지 않습니다. 각자 Claude 에게 **시작 메시지 하나**를 보내면 Claude 가 실행 문서(저장소 `coach/1주차/실행문서.md`)를 읽고 단계마다 질문을 합니다. 답만 하면 됩니다. GitHub 에 들어갈 일은 없습니다.

## 실행 문서로 진행하는 법

1. Claude 앱 Code 탭에서 내 저장소 폴더를 열고, 아래 시작 메시지를 붙여넣고 Enter.

```
저장소 최신 내용을 먼저 받아 줘(git pull). 그다음 coach/1주차/실행문서.md 를 읽고,
"오늘 끝나면 남는 것" 절을 나에게 그대로 보여 준 뒤 처음 단계부터 순서대로 진행해 줘.
단계마다 그 단계 제목과 할 일을 한 줄로 먼저 알려 주고, 질문은 한 번에 하나씩만 해 줘.
상자 안 지시문은 그대로 따르되, "안 뜨면"처럼 조건이 붙은 상자는 그 조건을 나에게 먼저 확인해.
"공통 세션에서는 하지 않음"이라고 적힌 단계는 오늘 건너뛰고 저장 단계로 가 줘.
한 단계가 끝나면 다음 단계로 넘어가도 되는지 나에게 물어봐. 단계에 적힌 조건(관문 통과 시만 등)을 지켜 줘.
```

2. Claude 가 실행 문서를 읽고 질문을 한 번에 하나씩 합니다. 답만 합니다. 모르면 "모름". 문서 안의 지시문은 Claude 가 알아서 실행하므로 복사할 필요가 없습니다.
3. PRD 는 내가 **"반영"** 이라고 말할 때만 고쳐집니다. 제안이 마음에 안 들면 "아니, ___로" 라고 답합니다. 하나도 반영하지 않으면 파일은 그대로입니다.
4. 실제 비밀번호·토큰·쿠키·시트 원본은 붙여넣지 않습니다. 가짜 이름이나 "모름"으로.
5. 막히면 손을 들거나 채널에 캡처 한 장. 한 단계가 10분 넘게 안 풀리면 건너뛰고 저장합니다.

## 공통 주제 ② — 만든 도구를 어디서 돌릴까

| 위치 | 어떤 경우 | 남이 쓸 수 있으려면 |
|---|---|---|
| 구글 서버 (Apps Script) | 구글 드라이브·시트를 읽고 슬랙에 보낼 때 | 실행 계정이 개인이 아니어야 한다 |

| 내 컴퓨터 | 연습·확인 단계 | 2주차 통과 불가. 다른 위치로 옮길 계획이 있어야 한다 |

2주차 통과 기준이 "조잡해도 남이 접속해서 쓸 수 있는 상태"이므로, 오늘 위치를 정해 두면 2주차가 쉬워집니다.
